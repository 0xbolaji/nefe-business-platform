# Release Notes

> **Summary:** Documentation v1 establishes a consistent, production-suitable source of truth for the NEFE Business Network concept and its capability boundaries.

## Documentation v1

Released: 24 July 2026

This release introduces:

- A guided path from [introduction](../getting-started/index.md) to [pilot preparation](../business/pilot-program.md).
- Platform concepts for the [Commerce Graph](../platform/commerce-graph.md), [Opportunity Engine](../platform/opportunity-engine.md), analytics, and AI.
- Operational guidance for merchants and consumers.
- Commercial frameworks for business model, revenue, and enterprise deployment.
- Security, privacy, access, integration, and API-readiness guidance.
- Reference answers and standardized terminology.

## Important boundary

This release documents both current concepts and future direction. Readers must observe the **Live**, **Pilot**, and **Proposed** labels on each page. It does not announce a public API, financial product, token issuance, autonomous AI capability, or universal production availability.
